```markdown
# PayEasy User Service

## Overview
The User Service is a Spring Boot microservice that handles user registration, login, profile management, and multi-factor authentication (MFA) for the PayEasy payment platform. It securely stores user information in an Oracle 19c database and exposes RESTful APIs for client applications.

## Features
- User registration with password hashing (MD5)
- User login with password verification and optional MFA
- Static MFA OTP verification (OTP: 1234 for now)
- Enable/Disable MFA functionality
- Update user profile (full name and mobile)
- Error handling and input validations

## Tech Stack
- Java 17+
- Spring Boot 3.3.2
- Spring Data JPA
- Spring Security (for future enhancements)
- Oracle Database 19c
- Maven for build and dependency management

## Setup Instructions

### Prerequisites
- Oracle Database 19c installed and running
- Java JDK 17 or higher
- Maven installed
- Port 8080 free for application

### Installation

1. Clone the repository:
   ```
   git clone <your-repo-url>
   cd user-service
   ```

2. Configure Oracle datasource in `src/main/resources/application.properties`:
   ```
   spring.datasource.url=jdbc:oracle:thin:@localhost:1521:XE
   spring.datasource.username=YOUR_DB_USERNAME
   spring.datasource.password=YOUR_DB_PASSWORD
   spring.jpa.hibernate.ddl-auto=update
   spring.jpa.database-platform=org.hibernate.dialect.Oracle12cDialect
   spring.datasource.driver-class-name=oracle.jdbc.driver.OracleDriver
   ```

3. Create the `USERS` table in your Oracle database (adjust as per your schema):

   ```
   CREATE TABLE USERS (
       user_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
       full_name VARCHAR2(100),
       email VARCHAR2(100) UNIQUE NOT NULL,
       mobile VARCHAR2(20),
       password_hash VARCHAR2(255) NOT NULL,
       mfa_enabled NUMBER(1) DEFAULT 0,
       created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
       updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
   );
   ```

4. Build and run the app:
   ```
   mvn clean install
   mvn spring-boot:run
   ```

## API Documentation

### Base URL
`http://localhost:8080/api/users`

### Endpoints

| Method | Endpoint                | Description                       |
| ------ | ----------------------- | -------------------------------- |
| POST   | `/register`             | Register a new user              |
| POST   | `/login`                | Login user                      |
| POST   | `/mfa/verify`           | Verify MFA OTP (static OTP: 1234) |
| POST   | `/mfa/enable/{userId}`  | Enable or disable MFA           |
| PUT    | `/profile/{userId}`     | Update user profile             |

### Sample Request / Response

#### Register User
**POST** `/register`

Request Body:
```
{
  "fullName": "John Doe",
  "email": "john@example.com",
  "mobile": "9876543210",
  "passwordHash": "password123"
}
```

Response:
```

  "passwordHash": "482c811da5d5b4bc6d497ffa98491e38",
  "mfaEnabled": false,
  "createdAt": "2025-08-27T09:53:43.703+00:00",
  "updatedAt": "2025-08-27T09:53:43.703+00:00"
}
```

## How to Test

Use Postman or curl commands to test the endpoints:

- Register user: `POST /api/users/register`
- Login user: `POST /api/users/login`
- Verify OTP: `POST /api/users/mfa/verify`
- Enable/Disable MFA: `POST /api/users/mfa/enable/{userId}?enable=true|false`
- Update profile: `PUT /api/users/profile/{userId}`
```
